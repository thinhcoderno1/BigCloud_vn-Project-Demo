# OS and application logos

Retrieved 2026-09-05. SVG files are bundled locally under public/images/catalog.
Brand artwork is used for product identification, without recoloring or stretching.

- Ubuntu, Debian, AlmaLinux, Rocky Linux, CentOS, Windows, Docker, WordPress,
  Node.js, PM2, Linux, NGINX, MariaDB, PHP, Apache, MySQL and GitLab:
  Devicon original-color SVGs, https://github.com/devicons/devicon/tree/master/icons
  (each local filename corresponds to icons/NAME/NAME-original.svg).
  The Windows four-pane mark is provided by Devicon under windows11; it represents
  the Windows product family here, not a Windows 11 operating system offering.
  Devicon is an independent logo collection; these are not claimed to be downloads
  directly from each vendor. Its MIT notice is retained in DEVICON-LICENSE.txt.
- n8n: https://github.com/n8n-io/n8n/blob/master/packages/nodes-base/nodes/N8n/n8n.svg
- Coolify: https://github.com/coollabsio/coolify/blob/main/public/coolify-logo.svg

LEMP and LAMP use separate logos of the components listed in the existing catalog,
not an invented stack logo. Node.js and PM2 each retain their own brand mark.
Docker's mark identifies Docker & Compose. Names, versions, descriptions and
catalog entries remain unchanged. Logos remain trademarks of their owners.
